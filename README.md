# ⚡ NOVA Router Manager Enterprise v5.0 (WISP Edition) - تطبيق حقيقي 100% بدون أي بيانات وهمية

تطبيق **NOVA Router Manager Enterprise v5.0** المخصص لمهندسي الشبكات وأصحاب منظومات الإنترنت (**WISP**)، مصمم ليتصل فعلياً براوترات **MikroTik (RouterOS v6 & v7)** عبر بروتوكول **API Port 8728** و **REST API** ويعرض بيانات حية ولحظية 100% من الراوتر مع فصل كامل بين **قسم البرودباند (PPPoE)** و **قسم الهوتسبوت والكروت (Hotspot)**.

---

## 🔥 أهم مميزات الإصدار الخامس (Enterprise v5.0):
1. **صفر بيانات وهمية (Zero Fake Data)**:
   - لا يعرض أي أسماء أو أرقام وهمية؛ يبدأ التطبيق ببوابة دخول مباشرة للراوتر (**NOVA MikroTik Login**) مع دعم حفظ عدة راوترات والتبديل بينها.
   - قراءة لحظية حقيقية كل ثانيتين لموارد الراوتر (`/system/resource/print` و `/system/health/print`) وحساب السرعة اللحظية الحقيقية بالـ `Mbps` لكل منفذ (`/interface/print`).
2. **قسم البرودباند (PPPoE) مستقل بالكامل**:
   - يعرض العدد الحقيقي للمتصلين الآن (`/ppp/active`)، إجمالي الحسابات (`/ppp/secret`)، الحسابات المعطلة، وباقات السرعة (`/ppp/profile`).
   - سحب حي لكل مشترك PPPoE متصل من واجهته الديناميكية `<pppoe-username>`.
   - إضافة وتعديل وحذف المشتركين، قفل الماك أدرس (`Caller-ID`)، طرد الجلسة النشطة (`Kick`)، وإنشاء باقات سرعة جديدة.
3. **قسم الهوتسبوت والكروت (Hotspot) مستقل بالكامل (منافس لـ Mikhmon)**:
   - تبويبات مستقلة لـ: الكروت (`/ip/hotspot/user`)، النشطين الآن (`/ip/hotspot/active`)، البروفايلات (`/ip/hotspot/user/profile`)، وتخطي/حظر الماك (`/ip/hotspot/ip-binding`).
   - **مولد دفعات كروت الهوتسبوت الاحترافي**: توليد من 1 إلى 200 كارت دفعة واحدة وإرسالها للراوتر مع تحديد البادئة (`Prefix`)، نوع الكارت (`User=Pass` أو مختلف)، البروفايل، المدة (`Limit-Uptime`)، والكوتا بالجيجا (`Limit-Bytes-Total`) مع الطباعة الفورية.
4. **أدوات وسكريبتات WISP حقيقية تفيد الشبكة**:
   - **كشف الأبراج والأجهزة المتصلة (`MNDP /ip/neighbor/print`)**: يعرض جميع قطع Ubiquiti و Mimosa و MikroTik المتصلة بالراوتر مع عناوين الـ IP والـ MAC والمنفذ.
   - **تثبيت سكريبت فصل المشتركين المنتهين تلقائياً (`/system/scheduler`)**، **حماية RAW ضد هجمات DNS الخارجي**، و**رفع أولوية البينج والألعاب (`ICMP Mangle`)**.
   - **فحص Ping و Traceroute حقيقي من داخل الراوتر**، إدارة الطوابير (`Simple Queues`)، تثبيت عناوين `DHCP Leases`، قراءة السجل الحي (`/log/print`)، وطرفية أوامر مباشرة (`Live Terminal`).
